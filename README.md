## 🛠️ Technology Stack & Architecture

- **Framework:** Next.js 14 (App Router)
- **Rendering:** Static Site Generation (SSG / Pre-rendering for instant loads & top Core Web Vitals)
- **Styling:** Custom Vanilla CSS Design System with CSS variables and responsive media queries
- **Structured Data:** Schema.org (`EmploymentAgency`, `LocalBusiness`, `BreadcrumbList`, `FAQPage`)
- **Metadata:** Open Graph tags, Twitter card, canonical URLs, dynamic XML sitemap (`/sitemap.xml`), and `robots.txt`
